ขั้นตอนการนำไฟล์ไปสร้าง Dashboard บน GitHub Pages (ฟรี)

เผยแพร่เว็บสถิติสาธารณสุขแบบเรียลไทม์ให้ทีมงานเข้าดูได้จากทั่วโลก

ขั้นตอนที่ 1: เตรียมไฟล์

เซฟโค้ดทั้งหมดนี้ไว้ในชื่อไฟล์ index.html ลงในคอมพิวเตอร์ของคุณ

ขั้นตอนที่ 2: สร้าง Repository บน GitHub
  1. เข้าเว็บ github.com แล้วล็อกอินเข้าใช้งาน
  2. กดปุ่ม New เพื่อสร้าง Repository ใหม่
  3. ตั้งชื่อ Repository เช่น health-dashboard (เลือกตั้งเป็น Public)
ขั้นตอนที่ 3: อัปโหลดไฟล์ index.html
  1. ในหน้า Repository ที่สร้างเสร็จแล้ว ให้คลิกคำว่า uploading an existing file
  2. ลากไฟล์ index.html วางลงในช่อง แล้วกดปุ่ม Commit changes
ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages
  1. ไปที่เมนู Settings ด้านบนของ Repo
  2. เลือกแถบ Pages ที่เมนูด้านซ้าย
  3. ตรงหัวข้อ Build and deployment เลือก Branch เป็น main แล้วกด Save
  4. รอประมาณ 1-2 นาที ท่านจะได้ลิงก์เว็บไซต์แบบ Live เช่น https://username.github.io/health-dashboard/ พร้อมแชร์ให้ผู้บริหารและทีมงานใช้งานได้ทันที!
